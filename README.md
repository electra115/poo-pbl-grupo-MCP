Sistema de Agendamento e Telemedicina — Clínicas Populares  Resumo do conteúdo:  Projeto desenvolvido em Java 17 + Maven. Usa DDD (Domain-Driven Design), Orientação a Objetos e TDD. Permite: Agendamento de consultas presenciais. Telemedicina (consultas online). Gerenciamento de links de videoconferência. Prontuário eletrônico. Receita médica digital. Possui três contextos principais: Paciente Agenda Médica Atendimento Define entidades como: Paciente Medico Consulta Prontuario Define Value Objects como: Cpf Email Crm Periodo ReceitaMedica Possui testes unitários para todas as classes principais. Utiliza GitHub Actions para compilar e executar testes automaticamente.
